Arquitetura de Microsserviços

Migração de Sistema Monolítico para uma Aplicação Descentralizada

O Trabalho de Conclusão de Curso pretende aplicar conceitos de engenharia de software moderna para: a partir de um repositório monolítico público(Aplicacão Web), realizar a segregação em microsserviços utilizando Java 21, Spring Boot, Angular e PostgreSQL. Serãk implementadas práticas de CI/CD, testes unitários, de integração e2e, além de ferramentas de qualidade de código (SonarCloud). O resultado é uma arquitetura escalável, resiliente e preparada para evolução contínua.

Java 21+ Angular 19 Spring Boot PostgreSQL

Arquitetura alvo: descentralizada e escalável
